# Creator Agent Studio

One topic in, a full content package out: a producer agent directs specialist agents in your browser to write a creative brief, a YouTube script, an X thread and a shot-by-shot storyboard, and asks the partner agentic website Hook Lab for scored opening hooks.

- Live site: https://creator-agent-studio.pages.dev/
- Agent network: https://creator-agent-studio.pages.dev/creator_agent_studio.network.json
- Partner site: Hook Lab, https://creator-hook-lab.pages.dev/ (source: https://github.com/zhangjihao05-design/creator-hook-lab)
- Built for the Open Agentic Web Challenge, following the open agentic web specification (https://github.com/cognizant-ai-labs/agentic-web).
